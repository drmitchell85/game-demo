# Hexwar

A Battle Brothers-inspired tactical combat game. Hobby project, vibes-driven development.

## What Is This?

Turn-based tactical combat on a hex grid. You move guys, they hit other guys, numbers go up or down. Eventually someone dies.

## Goals

- Learn game dev fundamentals (rendering, state, game loops).
- Get a playable tactical combat prototype working.
- Have fun. Mass no cathedrals.

## Non-Goals

- Shipping anything.
- Production quality code.
- Faithfully recreating Battle Brothers.
- Multiplayer.

## Tech Stack

- **Phaser 3** — 2D game framework.
- **TypeScript** — Type safety for game state.
- **Vite** — Bundler/dev server.
- **Claude Code** — Doing most of the typing.

## Roadmap (Loose)

1. Hex grid + camera controls.
2. Unit placement + movement.
3. Turn system.
4. Combat mechanics (attack, HP, damage).
5. Enemy AI (move toward things, hit things).
6. Unit stats + roster.
7. UI/UX polish.
8. Strategic layer (maybe never).
